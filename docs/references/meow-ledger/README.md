## 视觉与交互执行

- 采用奶油白底、极淡爪印、明黄色底栏／键盘面板、粉色重点和选中态、深色细描边，圆形分类图标带浅色底。图案和图标用项目内可维护的 SwiftUI 图形／系统符号绘制；不把营销海报贴进 App。
- 移除系统大标题、iOS 浮动玻璃 TabView 和默认灰色 Form／圆角大列表。使用紧凑自定义页眉、描边卡片、分组记录与固定底栏。
- iPhone 入口使用明细、账单、居中“＋”、账本、我的；其中账本替代参考图中尚未实现的存钱入口，保留当前可用功能，不增加假按钮。
- 记账页按图 2 排列：支出／收入切换、4 列圆分类网格、备注与金额横条、账本与日期、自定义 4 列数字键盘。右列依次为今天、＋、－、完成；其他键为 7–9、4–6、1–3、点／0／退格。输入及加减运算均以整数分计算，错误保留输入。
- 明细日历与月切换显示真实所选账本数据，日期选择与列表一致；账单显示真实月收支及结余。预算、猫咪收集、存钱和未实现功能不作为可点击入口出现。
- 详情以票据布局展示实际记录，保留编辑、删除确认和错误反馈。账本与“我的”未在参考图中完整展示，沿用相同视觉组件适配当前功能，不能声称逐像素复刻这些未知页面。
- Mac 保留桌面侧栏与键盘操作，采用同一配色、描边、分类和票据组件；产品名仍为有落。
