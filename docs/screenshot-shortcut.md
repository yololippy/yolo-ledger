# iOS 快捷指令截图记账

## 当前闭环

有落在 iOS 17 及以上提供“截图记账”App Intent。快捷指令把图片作为 `IntentFile` 传入后，有落使用 Apple Vision 在设备本地识别文字，再提取候选金额、商户、交易时间、收支方向和分类建议。识别结果不会直接写入账库，而是打开“确认截图记账”页面，由用户核对账本、分类、金额、日期和备注后保存。

当前只保留结构化识别结果，不保存原始截图，也不会申请照片图库权限。用户主动通过快捷指令传入图片；图片识别在设备上完成。

Apple 接口依据：

- [App Intent 参数](https://developer.apple.com/documentation/appintents/adding-parameters-to-an-app-intent)：`IntentFile` 可作为快捷指令输入。
- [Vision 图片文字识别](https://developer.apple.com/documentation/vision/recognizing-text-in-images)：文字识别在设备端执行。
- [喵喵记账 App Store 页面](https://apps.apple.com/cn/app/id1483024444)：公开页面确认其提供自动记账能力，但没有公开截图解析规则；有落不推断或复制其内部算法。

## 创建快捷指令

也可以在有落中打开“我的 → 轻点两下，截图记账”，按页面内三步指引配置，并直接跳转到“快捷指令”App。

1. 打开 iPhone 的“快捷指令”App，新建快捷指令。
2. 添加系统动作“截取屏幕”。也可以使用“选择照片”，方便用历史支付截图测试。
3. 搜索“有落”，添加“截图记账”。
4. 确认“支付截图”连接到上一步的图片输出。
5. 命名为“有落截图记账”并运行。识别完成后会打开有落确认页。

若要用轻点背面触发：进入“设置 → 辅助功能 → 触控 → 轻点背面”，将轻点两下或三下绑定到“有落截图记账”。不同 iOS 版本的设置名称可能略有差异，以系统实际界面为准。

iOS 不允许第三方 App 自动替用户修改“轻点背面”设置，因此首次绑定必须由用户在系统设置中完成；绑定后，轻点背面两下即可执行“截取屏幕 → 本地识别 → 打开有落确认”的完整链路。

## 当前识别规则

- 优先识别“实付、支付金额、付款金额、退款金额、到账金额”等最终金额，降低优惠、红包、余额、原价等数字的权重。
- 若现金“实付款”为 0，但超市卡、礼品卡或储值卡已经实际扣款，则使用该支付方式的扣款金额；商品展示价和各项优惠不作为最终消费金额。
- 排除交易时间、订单号、交易单号和流水号等长数字。
- 识别“商户、收款方、付款给、交易对象”等标签，并用附近文本补充商户候选。
- 只有“退款成功、退款金额、已退款、已收款、到账金额”等明确结果才按收入建议处理；“极速退款、退货包运费”等订单服务说明仍按普通支出处理。
- 根据商户和截图文本提供基础分类建议；无法明确匹配时使用“其它”或“其他收入”。
- 日期采用截图中的交易时间；无法识别时使用当前手机本地日期。
- 进入确认页后自动填写金额、收入／支出、分类和商户备注，仍由用户核对并点击完成。

## 安全边界与后续工作

- 当前始终要求确认，不自动保存；这是为了避免 OCR 或金额候选错误污染账本。
- 当前只保留最近一次待确认结果；新的截图会覆盖尚未打开的旧结果。
- 尚未实现重复截图／重复交易检测、可配置商户分类规则、识别结果撤销和批量连续识别。
- 模拟器已验证快捷指令结果到确认页及保存流程；快捷指令系统动作、轻点背面和真实支付截图仍需在连接的 iPhone 上完成验收。
