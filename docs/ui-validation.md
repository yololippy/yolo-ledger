# 喵喵记账参考 UI 验收

2026-10-28，基于[已归档官方参考](references/meow-ledger/README.md)，完成当前已实现功能的 UI 重做。M2 原有本地记账功能保留；本页记录此次界面改动，之前的功能验收见 [M2 记录](m2-validation.md)。

## 页面覆盖

以下页面曾在 iPhone 18 Pro / iOS 27.0 模拟器实际运行验证，使用隔离测试账库与虚构数据。相关截图已按用户要求从仓库移除，仅保留验证范围和结果。

| 页面 | 本次实现 |
| --- | --- |
| 账单 | 紧凑账本页眉、月份切换、描边结余卡、收支条与日分组 |
| 明细 | 月日历、按日筛选、选中态、当日收支与记录、查看整月 |
| 记账 | 支出／收入、四列分类插画、备注金额条和固定数字键盘 |
| 详情 | 白色描边小票、虚线、锯齿底边、真实记录、编辑与删除确认 |
| 账本 | 账本卡片、当前选择、新建及重命名 |
| 我的 | 有落名称、本地保存状态与共享视觉组件 |

固定底栏为“明细／账单／＋／账本／我的”；尚未实现的存钱入口以已有账本能力替代。背景爪印与分类插画由代码绘制，官方宣传图不作为应用素材打包。Mac 使用同一视觉组件，保留左侧导航、键盘输入和快捷操作。

## 验证结果

- Core 38 项测试通过：原有 26 项与金额表达式 12 项。键盘加减以整数分计算，支持负数中间结果，校验最终正金额、精度、格式及溢出；`12.` 可完成为整数金额，`1.2.` 会被拒绝。
- UI 状态 9 项测试通过。除原有保存、失败和取消竞争场景外，覆盖日期／月份筛选、刷新保留浏览月份，以及从其他日期保存后自动显示新记录。
- iPhone 4 项完整流程在同一轮通过：导航、账本新建／重命名／切换和收入隔离、记账 CRUD 与重启、启动失败重试。记账流程验证 `12.34+7.66-5=15.00`、非法精度保留输入、备注键盘返回、日历筛选、修改为 `23.45`、重启保留、删除后重启仍为空。
- 日历顶部留白与底栏描边修正后，扩展导航用例再次通过，覆盖日期面板、账本菜单选项及取消。
- 双端 Debug 构建通过。main 实际查看六类 iPhone 页面，并在 Mac 验证侧栏、账单和小票显示、Cmd+N、金额表达式保存、中文备注、按日筛选与新进程读取已保存记录。测试实例已退出。
- Storage 本轮无改动；M2 的 15 项存储测试结果保留，不声称本轮重新执行。

## 边界

当前依据为官方公开截图，未覆盖的账本／我的完整页面按相同视觉组件适配；不将此结果描述为安装版所有页面的逐像素复刻。未实现的分类管理、定时记账、导入导出等页面继续随里程碑推进。真机、旧系统兼容性与完整参考录屏仍待验收；iPadOS 不在支持范围内。

## 用户截图分类补齐（2026-10-28）

用户随后提供实际记账页截图，分类顺序已按[补充参考](references/meow-ledger/README.md#用户补充的支出分类截图)接入：餐饮、交通、购物、宠物、住房、零食、旅行、通讯、医疗、Pos、其它、礼金、运动。额外保留旧“日用”置末，共 14 个支出分类；收入仍为工资、奖金、其他收入。“设置”是管理入口，不存为分类，也不添加无功能的占位按钮。

- Core 42 项测试通过，新增分类顺序、名称、稳定 ID 与收入兼容性验证。
- Storage 20 项测试通过，含 5 项真实磁盘升级测试。旧 8 分类库自动补齐为 17 分类；原“其他支出”沿用 ID，仅在仍是旧默认名时改为“其它”。账目、账本和自定义数据保留，升级失败回滚，成功后重开不重复执行；数据库 schema 仍为 V1。
- UI 状态 9 项测试通过；iPhone 两项分类专项测试验证逐个选中全部 14 个支出与 3 个收入分类，并验证“运动／宠物”保存后重启，详情名称、金额与备注仍正确。
- main 使用旧 Mac 隔离账库实际打开新版：原 3 条记录与收支合计保持，新分类完整出现，可滚动并选择末行“运动”，取消后退出测试实例。

最终验证覆盖完整支出分类、末行选中态和收入分类。iPhone 18 Pro 上四行完整可见，窄列按可用宽度缩小并保留滚动；尚未实际验收窄屏设备。

双端最终构建通过。两项专项结果为 `/tmp/yolo-ledger-categories-ios.xcresult`；行距、通讯听筒及自适应列宽收尾后，分类逐项选择用例复测通过，结果为 `/tmp/yolo-ledger-categories-ios-responsive-final.xcresult`。

## 有落亮蓝品牌色试用（2026-10-28）

用户选择亮系统蓝图标方向后，将 `#0A84FF` 用于应用 tint 与选中态；底部导航、键盘面板和详情背景统一使用粉彩浅蓝 `#C6E2FF`。图标中的橙色继续用于“完成”和关键金额，收入、支出保留独立语义色，分类插画不被主色覆盖。临时 Debug 调色器及其测试已按用户要求删除。

所有共享页面、组件和代码绘制插画已改为从 SwiftUI Environment 读取语义化 `LedgerTheme`，实际 RGB 色值集中在 `LedgerThemeValues.swift`。双端 App 通过同一组装入口注入 `.pastel`；未来新增暗黑模式或可选主题时增加主题预设并切换注入值，不需要逐页替换颜色。

验证结果：共享 UI 9 项状态测试通过；iOS 与 macOS Debug / Release 构建通过。此次验证配色和主题注入架构，当前页面结构仍属于历史临时界面，不作为后续有落独立 UI 的设计规范。

## 自研年月选择器（2026-10-28）

账单与明细的年月标题已改为可点击入口，并共用浏览月份状态。iPhone 采用去除无效拖拽区的紧凑 Sheet，Mac 采用标题锚定 Popover；默认显示 3 × 4 月份网格，点击年份后切换到每页 12 年的年份网格，左右按钮每次前后翻 12 年。月份页支持横向滑动切换年份；月份高亮同时匹配年份，切到其他年份不会残留旧月份高亮；“回到本月”只恢复面板中的当前年月而不关闭，年份页的“返回月份”为可操作按钮。iPhone 禁用系统拖拽关闭，避免横滑带少量纵向偏移时误关，并提供明确关闭按钮。选择月份后关闭面板并同步更新两个页面。交互和视觉由项目自行实现，未复制或依赖调研项目的代码。

共享 UI 10 项状态测试通过；iPhone 模拟器专项 UI 测试覆盖月份／年份两种面板、带纵向偏移的横滑保持面板、跨年高亮、回到本月不关闭、年份返回、明确关闭、选择目标年月以及账单／明细同步。iOS 与 macOS Debug / Release 构建通过。
